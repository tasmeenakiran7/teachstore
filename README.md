# Teach Store

Teach Store is a modern React-based educational website built with Vite.  
It provides a clean and responsive user interface for showcasing courses, educational content, and academy services.

## 🚀 Features

- Responsive design
- Modern UI/UX
- Fast performance with Vite
- React component-based structure
- Smooth navigation
- Educational/course showcase sections

## 🛠️ Technologies Used

- React.js
- Vite
- CSS
- JavaScript
